# نمایش آب‌وهوای زنجان و قائن

برد: ESP32-WROOM-32؛ نمایشگر: LCD1602 با رابط I2C.
برنامه مستقل است؛ آپلود آن جای برنامه قبلی روی همان ESP32 را می‌گیرد.
این پروژه به وای‌فای ۲٫۴ گیگاهرتز دارای اینترنت نیاز دارد؛ هیچ سنسور دما لازم نیست.

## ۱. سیم‌بندی — با برق قطع
مبدل I2C پشت LCD با مبدل سطح ولتاژ متفاوت است. برای LCD با تغذیه ۵ ولت و مقاومت‌های Pull-up به ۵ ولت، یک مبدل سطح منطقی دوطرفه مناسب I2C مثل BSS138 استفاده کنید.

| اتصال | مقصد |
|---|---|
| ESP32 GPIO21 | LV1 مبدل سطح |
| ESP32 GPIO22 | LV2 مبدل سطح |
| HV1 مبدل سطح | SDA نمایشگر |
| HV2 مبدل سطح | SCL نمایشگر |
| LV مبدل سطح | 3V3 برد |
| HV مبدل سطح | منبع 5V |
| VCC نمایشگر | همان منبع 5V |
| GND نمایشگر و مبدل | GND مشترک با ESP32 |

کابل USB برد را تغذیه می‌کند. اگر برد شما خروجی 5V مشخص دارد و از USB تغذیه می‌شود، می‌توان همان خروجی را برای LCD و سمت HV به کار برد. پایه‌ها را براساس برچسب واقعی برد شناسایی کنید؛ 5V به پایه 3V3 یا GPIO ندهید.
اتصال مستقیم SDA/SCL با Pull-up پنج‌ولتی به ESP32 مناسب نیست. اگر مبدل سطح ندارید، قبل از سیم‌بندی عکس و مشخصات پشت LCD را بفرستید.
کتابخانه آدرس I2C و چینش پایه‌های مبدل LCD را خودکار پیدا می‌کند؛ نیازی به حدس 0x27 یا 0x3F نیست.

## ۲. کتابخانه‌ها و برد
در Arduino IDE > Boards Manager:
- esp32 by Espressif Systems: نسخه **3.3.11**
- Board: **ESP32 Dev Module**

در Library Manager:
- **hd44780 by Bill Perry: 1.3.2**
- **ArduinoJson by Benoit Blanchon: 6.21.5**

کتابخانه‌های WiFi، HTTPClient و WiFiClientSecure همراه بسته ESP32 هستند.
کتابخانه BLE Keyboard پروژه قبلی در این برنامه استفاده نمی‌شود.

## ۳. تنظیم وای‌فای
پوشه را Extract کنید و فایل ESP32_Weather/ESP32_Weather.ino را باز کنید.
همه فایل‌های h کنار ino بمانند.
در تب Config.h فقط این دو مقدار را با اطلاعات خودتان جایگزین کنید؛ علامت نقل‌قول بماند:

```cpp
static const char WIFI_SSID[] = "YOUR_WIFI_NAME";
static const char WIFI_PASSWORD[] = "YOUR_WIFI_PASSWORD";
```

نام و رمز وای‌فای را لازم نیست برای من بفرستید.
Port را انتخاب کنید و Upload بزنید. Serial Monitor: سرعت 115200.

## ۴. نمایشگر
هر صفحه ۴ ثانیه نمایش داده می‌شود؛ چرخه کامل ۱۶ ثانیه است:
۱. نام Zanjan و دما به سانتی‌گراد
۲. رطوبت زنجان به درصد و سرعت باد به کیلومتر بر ساعت
۳. نام Qaen و دما
۴. رطوبت و باد قائن

اطلاعات هر شهر هر ۱۰ دقیقه درخواست می‌شود. در صورت خطای API، تلاش بعدی بعد از یک دقیقه است.
- WiFi connecting: در حال اتصال؛ نام/رمز و باند ۲٫۴ گیگاهرتز را بررسی کنید.
- Syncing clock: منتظر ساعت اینترنتی برای اعتبارسنجی HTTPS؛ ممکن است شبکه دسترسی NTP را محدود کرده باشد.
- Loading weather: هنوز پاسخ معتبر دریافت نشده.
- API retry...: دریافت ناموفق؛ متن خطا در Serial Monitor است.
- *OLD کنار شهر یا * کنار رطوبت: آخرین داده موجود نمایش داده می‌شود، ولی وای‌فای قطع شده، درخواست اخیر ناموفق بوده، یا بیش از ۲۰ دقیقه از دریافت گذشته است.

داده قدیمی با صفر جایگزین نمی‌شود. با قطع برق، داده‌ها پاک می‌شوند؛ پس از روشن‌شدن مجدد برای اولین دریافت اینترنت لازم است.
این داده‌ها خروجی مدل هواشناسی Open-Meteo هستند؛ سنسور داخل خانه یا اندازه‌گیری دقیق محله شما نیستند.
نام دو شهر در کد ثابت است؛ موقعیت دستگاه با GPS تشخیص داده نمی‌شود.

## ۵. عیب‌یابی
اگر صفحه روشن است ولی نوشته ندارد، پیچ آبی تنظیم کنتراست پشت LCD را آرام بچرخانید.
اگر Serial پیام LCD initialization error داد، سیم‌بندی و سطح ولتاژ را بررسی کنید. مثال I2CexpDiag کتابخانه hd44780 برای تشخیص اتصال مناسب است.
در صورت HTTP منفی، اینترنت، DNS، ساعت و گواهی HTTPS را بررسی کنید. اعتبارسنجی TLS در این کد فعال است؛ setInsecure استفاده نشده است.
ریشه گواهی ISRG Root X1 همراه پروژه آمده؛ تغییر زنجیره گواهی سرویس در آینده ممکن است به تعویض RootCA.h نیاز داشته باشد.
